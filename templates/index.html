Instalação e Configuração do Agente

Siga as instruções abaixo para conectar novas máquinas corporativas ao monitoramento da Givova Transportes.

URL do Servidor (Endpoint)
http://SEU_SERVIDOR:5000/api/agent/report
Token do Agente (X-Agent-Token)
{{ config.AGENT_SECRET_TOKEN or 'givova_agent_token_dev_2026' }}
Arquivo de Configuração Local (agent_config.json):
{
    "server_url": "http://127.0.0.1:5000/api/agent/report",
    "agent_token": "{{ config.AGENT_SECRET_TOKEN or 'givova_agent_token_dev_2026' }}",
    "department": "Logística",
    "display_name": "PC Expedição 01",
    "interval_seconds": 5
}
Passo a passo para implantar em um computador:
  1. Certifique-se de que a máquina possui Python 3.8+ instalado.
  2. Copie o script agente.py e instale as dependências: pip install psutil requests.
  3. Crie o arquivo agent_config.json ajustando a URL e o setor da máquina.
  4. Execute: python agente.py ou configure como tarefa agendada do Windows (Task Scheduler).
